Ayuda y Normas de Referencia
Guia de uso y marco normativo para peritaje de evidencia digital

📚 Marco Normativo

ISO/IEC 27037:2012
Tecnologias de la informacion - Tecnicas de seguridad - Directrices para la identificacion, recoleccion, adquisicion y preservacion de evidencia digital. Esta herramienta implementa los principios de integridad, autenticidad y cadena de custodia requeridos por esta norma.
ACPO Good Practice Guide for Digital Evidence (v5)
Principio 1: No se debe alterar ninguna evidencia que pueda ser presentada ante un tribunal. Principio 2: Toda persona que acceda a la evidencia original debe ser competente para hacerlo. Principio 3: Debe mantenerse una pista de auditoria o registro de todos los procesos. Principio 4: El responsable de la investigacion debe asegurarse de que se cumplan estos principios.
RFC 3161 - Sellos de Tiempo de Confianza (TSA)
IMPORTANTE: Los timestamps generados por esta herramienta son basados en el reloj del dispositivo local. Para maxima validez legal, se recomienda complementar con un servicio TSA (Time Stamp Authority) externo certificado. Los hashes SHA-256 garantizan la integridad del contenido capturado.

📝 Guia de Uso

1
Configure el caso: Ingrese los datos del expediente y sus credenciales como perito en "Configuracion del Caso". Estos datos apareceran en todos los informes.
2
Capture evidencias: Use "Nueva Evidencia" para registrar cada URL. Complete todos los campos disponibles: capturas de pantalla, codigo fuente, informacion tecnica y observaciones periciales.
3
Verifique los hashes: Cada evidencia genera un hash SHA-256 automaticamente. Use "Lista de Evidencias" para verificar la integridad en cualquier momento.
4
Cadena de custodia: Todas las acciones se registran automaticamente. Puede agregar entradas manuales para documentar transferencias, analisis y presentaciones ante el tribunal.
5
Exporte el informe: Genere el informe PDF para presentar ante el tribunal, descargue el paquete ZIP para preservacion y el CSV para analisis adicional.

📊 Sobre INDAGO FORENSE

INDAGO FORENSE es una herramienta standalone de recoleccion de evidencia digital para peritos informaticos. Funciona completamente en el navegador, sin necesidad de servidor ni instalacion.


Almacenamiento: Todos los datos se guardan en localStorage del navegador. Use la funcion de exportacion JSON para hacer backups regulares.


Privacidad: Ningun dato sale del dispositivo. No hay conexion a servidores externos (excepto CDN para las librerias al cargar la pagina).


Hashing: Se utiliza la Web Crypto API nativa del navegador para calcular hashes SHA-256, garantizando la implementacion mas segura disponible.


Nota legal: Esta herramienta es una ayuda para el perito. La validez legal del peritaje depende de los procedimientos del perito, la jurisdiccion y las normas procesales aplicables. Consulte siempre la legislacion vigente y los requisitos especificos del tribunal interviniente.
